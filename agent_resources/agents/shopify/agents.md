## Skills

- **`shopify-products`** — Shopify products and listings: search what is live, publish existing SellerClaw catalog products as listings, edit / sync stock / price / title, toggle visibility, delete. Cannot create products from scratch — catalog rows come from the supplier side.
- **`shopify-storefront-setup`** — non-product storefront content: pages, collections, navigation menus, shop settings, theme.
